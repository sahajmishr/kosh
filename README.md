# Kosh

> Your BharatCode API key, with a budget, a memory, and a receipt.

A drop-in, OpenAI-compatible gateway for the BharatCode Model API that cuts
wasted GPU work, survives queue saturation, and shows you what you spent.

## Why

On a shared GPU, every token you send that did not need sending is capacity
somebody else could have used.

**The cheapest token is the one you never send.**
